# Reporting a vulnerability

Please report suspected vulnerabilities privately to [Colin Devroe](mailto:colin@cdevroe.com). Include the Rinku version, operating system, affected feature, reproduction steps, and potential impact. Use synthetic data and omit credentials or private library contents.

Please allow time to investigate and prepare a fix before publishing details. Ordinary bugs and feature requests can be filed as GitHub issues. Rinku is early-stage software; fixes are delivered in the latest release rather than maintained release branches.
